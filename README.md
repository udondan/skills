# skills

Agent skills and the `udondan` Claude Code plugin marketplace.

## Install plugins with Claude Code

```console
claude plugin marketplace add udondan/skills
claude plugin install reminders-cli@udondan
```

Available plugins:

| Plugin | Description | Source |
| --- | --- | --- |
| `reminders-cli` | Read, add, edit, complete and delete macOS Reminders from the command line. | [udondan/reminders-cli](https://github.com/udondan/reminders-cli) |

## Skills in this repository

The `skills/` directory holds standalone skills that are not yet packaged as plugins. Copy a
skill directory into your agent's skills location to use it.
